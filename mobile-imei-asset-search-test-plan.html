Testing Notes

Camera scan tests (TC-UI-006, TC-UI-014, TC-UI-015) require a physical mobile device or a simulator with camera simulation support — they cannot be executed in a browser emulator alone. For TC-UI-007 and TC-UI-008/009, use network throttling tools or a staging backend configured to return errors. TC-UI-016 requires seeded test data with duplicate GPS IDs; confirm with the backend team before execution.
